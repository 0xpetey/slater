# The Fast on-device model is the default; Accurate is optional and per-Shot

macOS 26.4 offers two on-device Japanese → English models. Measured on 18 business texts, the Fast model (`TranslationSession.Strategy.lowLatency`) takes about 20 ms per text against about 380 ms for the Accurate model (`.highFidelity`), 19× faster, and loads in 62 ms instead of 1.8 s. Its wording is comparable on business text: sometimes better, occasionally more awkward. Since Slater's whole point is reading a screen without breaking flow, Fast is the default and the model onboarding requires. Accurate is optional: onboarding offers to download it, Settings can make it the default, and any Shot translated with Fast can be translated again with Accurate (the A key, the hover button or the details panel), with the Fast translations staying visible until each Accurate one lands. Both models stay on this Mac (ADR 0001).
